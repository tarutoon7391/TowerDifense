# 迷宮の守護者（fantasy-maze-td）

ブラウザで遊べるファンタジー風・迷路建築型タワーディフェンス。
Node.js + Express + Canvas 2D。ゲームロジックは `shared/` に完全分離し、
ブラウザと Node の両方から同じコードを import できる（将来のサーバー権威化を想定）。

本番: https://web-production-08d0a0.up.railway.app （GitHub main への push で自動デプロイ）

## 構成

```
server.js            Express: public/ と shared/ を静的配信（PORT 未設定時 3000）
shared/              ゲームロジック（ESM。DOM/Math.random/Date.now を使わない）
  config.js          ステージ・建築60種・敵・ウェーブ・経済・強化倍率の全パラメータ
  rng.js             シード付き疑似乱数（mulberry32）
  state.js           JSON 化可能なゲーム状態の生成（ステージの地形をグリッドに展開）
  pathfinding.js     ゴールからの BFS（フローフィールド）・到達判定・表示用経路
  towers.js          レベル別ステータス・強化費用の計算
  buffs.js           支援建築のバフ集計（最大値が有効）と経済系の全体修正値
  commands.js        placeTower / sellTower / upgradeTower / startWave（+ 副作用なしの canPlaceTower）
  simulation.js      step(state): 1tick = 1/30 秒 進める
public/              描画・入力（素の JS + ESM、外部アセットなし）
  js/main.js         ステージ選択、ジャンルタブ、rAF + 固定タイムステップのループ、HUD
  js/renderer.js     Canvas 2D 描画（図形のみ。地形・塔・敵・弾・演出・ミニマップ）
  js/input.js        マウス入力 → コマンド呼び出し / 建物の選択 / 壁のドラッグ配置
test/                node --test によるユニットテスト（41件）
agent.py             Claude Agent SDK によるレビュー用スクリプト（ゲーム本体とは無関係）
```

## ゲーム内容

### ステージ（4面・順番に解放。`?all=1` で全解放）

| # | 名前 | マップ | ウェーブ | 特徴 |
|---|------|--------|----------|------|
| 1 | 草原の門 | 20×12 | 10 | 障害物なし。基本の迷路づくり |
| 2 | 渓谷の道 | 22×13 | 12 | 岩に挟まれた細い谷。スライム・コウモリ・骸骨兵が登場 |
| 3 | 凍てつく湖 | 24×14 | 14 | 中央の湖を迂回する長い道。トロル・暗黒騎士 |
| 4 | 魔王城 | 26×16 | 16 | 岩と水の入り組んだ地形。11ウェーブ目と最終ウェーブに魔王 |

### 建築（5ジャンル × 12種 = 60種。石壁以外は3段階強化可）

画面右のタブでジャンルを切り替える（Tab キーでも切替、1〜9 で表示中ジャンルの建築を選択）。

**近距離**（射程は短いが火力が高い）
茨の壁 / 槍兵の櫓 / 火炎放射器（炎上）/ 剣闘士の塔 / 聖光の祭壇（アンデッド2倍）/ 氷柱の結界（減速）/ 衝撃槌（気絶）/ 竜の火口 / 処刑台（HP25%以下を即死）/ 散弾の櫓（3体同時）/ 大樹の守り手（押し戻し）/ 鎖の塔（2マス引き戻し）

**遠距離**（広く長く届く主力）
アーチャー塔 / 弩兵の塔（クリティカル）/ 風の弩（対空）/ バリスタ（鎧貫通）/ 連弩 / 爆炎の投石台（範囲・着弾予測）/ 魔導砲（直線貫通）/ 雷の尖塔（連鎖）/ 月光の弓（同一目標で威力上昇）/ 迫撃砲 / 狙撃手の塔（ボス1.5倍）/ 流星の塔（範囲・炎上・対空可）

**支援**（範囲内の塔を強化。同じ効果は重複せず最大値だけ有効。強化で上乗せ分が伸びる）
軍旗（攻撃+10%）/ 見張り塔（射程+0.5）/ 照明塔（対空+30%）/ 戦太鼓（間隔−15%）/ 鍛冶屋（攻撃+20%）/ 砥石台（物理+25%）/ 魔力の泉（魔法+25%）/ 祈りの祠（クリ率+10%）/ 賢者の塔（状態異常時間+50%）/ 占星台（広範囲に射程+0.8）/ 司令塔（複合）/ 英雄像（隣接のみ攻撃+35%）

**妨害**（減速・毒・鎧低下・気絶・押し戻し）
泥沼の呪具 / 氷の魔導塔 / 毒の祭壇 / 網投げ台（気絶・対空2倍）/ 呪いの塔（鎧−6・被ダメ1.2倍）/ 弱体の瘴気（範囲呪い）/ 幻惑の鏡（3マス押し戻し）/ 吹雪の塔（範囲減速）/ 疫病の祭壇（範囲毒・対空可）/ 凍結の杖（35%で1秒凍結）/ 腐食の霧（鎧−10）/ 重力の塔（強減速・対空2倍）

**特殊**（壁と経済）
石壁 / 門柱（壁＋隣接の射程+0.2）/ 金鉱（収入）/ 市場（所持金の5%利息）/ 魔法の苗木（毎ウェーブ収入が育つ）/ 賞金首の掲示板（周囲の撃破+3）/ 偵察気球（3ウェーブ先まで表示）/ 祈りの泉（ライフ+1/ウェーブ）/ 商人の宿（売却率70%）/ 練兵場（強化費20%引き）/ 錬金炉（建物数×2）/ 宝物庫（クリアボーナス1.5倍）

- 売却は投資額（建設費＋強化費）の 50%（商人の宿で 70%）が戻る。投資額の大きい建物は売却モードでは即売却されず、選択→「売却」ボタンで確定する
- 撃破報酬はウェーブのHP倍率に応じて増える（`ECONOMY.rewardHpScale`）
- ゲームオーバー時は「このウェーブからやり直す」で直前のウェーブ開始前に戻れる

### 敵（11種）

| 敵 | 特性 |
|----|------|
| ゴブリン / ウルフ / オーク | 標準 / 高速・低HP / 低速・高HP |
| スライム | 倒すと小スライム2体に分裂 |
| コウモリ / ガーゴイル | 飛行（迷路を無視して直進）。ガーゴイルは鎧あり |
| 骸骨兵 | 鎧（物理ダメージを固定値で軽減）・アンデッド |
| トロル | 高HP・毎秒再生 |
| 暗黒騎士 | 厚い鎧・アンデッド・到達でライフ2 |
| 魔王（ボス） | 超高HP・鎧・再生・スロウ耐性50%・気絶/押し戻し/即死が効かない・到達でライフ10 |

準備中は「次のウェーブ」の敵名にマウスを乗せると HP・速度・鎧などが表示される。

## ローカル起動（Windows PowerShell）

```powershell
cd $env:USERPROFILE\Desktop\fantasy-maze-td
npm install
npm test
npm start
# ブラウザで http://localhost:3000 を開く
```

ポートを変える場合:

```powershell
$env:PORT = "8080"; npm start
```

## 遊び方

- 左クリックで選択中の建物を設置。石壁はドラッグで連続配置できる
- 既存の建物をクリックすると選択され、実効ステータス（支援効果込み）・強化後の数値・売却額を確認して強化/売却できる
- 右クリック / Esc で選択解除、Tab でジャンル切替、1〜9 で建築選択、S で売却、U で強化、Space でウェーブ開始
- 敵は常にスタート→ゴールの最短経路を進む。石壁で迷路を作って足止めする。設置プレビュー中は「置いた後の経路」が白い点線で表示される
- 飛行する敵は迷路を無視して直進する（次のウェーブに飛行がいるときは紫の破線でルート表示）
- 経路を完全に塞ぐ配置、門と城・岩・水の上、ウェーブ中の建築/売却/強化はできない
- 全ウェーブ撃退でクリア。ライフ 0 でゲームオーバー

## Railway デプロイ

- GitHub の main に push → Railway がそのままビルド・起動する（連携済み）
- Start Command: `npm start`（package.json の scripts.start = `node server.js`）
- PORT: Railway が注入する `process.env.PORT` をそのまま使用。手動設定不要
- Node バージョン: package.json の `engines.node` (>=20) に従う
- ビルドステップ・環境変数は不要（依存は express のみ）

## 設計上のルール

- 状態変更は `shared/commands.js` のコマンドと `simulation.step()` だけが行う
- ゲームバランスの数値は `shared/config.js` に集約し、ロジック内にハードコードしない
- `shared/` は決定的: 同じシード・同じコマンド列なら同じ結果になる（クリティカル・気絶・押し戻しの判定もシード乱数）
- `state.effects` は演出用の一時データ。ロジックの結果には影響しない
